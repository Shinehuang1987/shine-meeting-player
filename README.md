# Shine Meeting Player

Obsidian 会议音频与时间戳转录同步播放器，支持桌面和安卓。当前发布为 **0.3.0 测试版**。

## 安卓通过 BRAT 安装

1. 在 Obsidian 社区插件中安装并启用 BRAT。
2. 在 BRAT 中添加本仓库地址，选择最新版本并安装。
3. 启用 Shine Meeting Player。
4. 确认坚果云已把转录笔记和音频下载到手机的 Obsidian 库内。仅在坚果云 App 中看得到文件，并不代表已同步进 Obsidian 库。
5. 打开带时间戳的笔记，通过命令面板执行“Shine Meeting Player：打开当前笔记的音文同步播放器”。可把此命令加入移动端工具栏。

本仓库仅包含通用插件代码与合成测试，不含会议音频、业务笔记或个人配置。笔记与音频可继续使用既有坚果云同步，插件不负责云盘登录或同步。

## 笔记属性

```yaml
audio: "Attachement/会议音频/meeting.mp3"
audio notes: "Notes/会议摘录"
```

- **选择库内音频**：搜索当前库里的音频并将相对路径写入 `audio`。桌面端额外保留系统文件选择窗口。
- **摘录笔记路径**：选择库内目标笔记并写入 `audio notes`。
- 也识别正文中的 `> 源文件：...`，并兼容旧的 `meeting_excerpt_target` 属性。
- 手机不能读取电脑上的 `D:/...` 路径，请改用库内相对路径。

## 播放与摘录

- 播放器位于原笔记编辑区顶部，不复制显示转录稿；建议使用实时预览/源码模式。
- 前后跳转 3 秒、倍速、蓝色当前段高亮、跟随原笔记。选中文字时暂停自动滚动。
- 安卓：长按选择单词、句子或段落，点播放器“摘录选中文字”。也可执行同名命令并加入移动端工具栏。桌面保留右键摘录。
- 摘录附原笔记链接与音频时间点；精度以原稿时间戳为准，不提供逐词强制对齐。
- 字幕延后秒数：正数晚出现，负数早出现。光标放在目标句后点击“当前句对齐此刻”，可校准整篇固定偏移。
- 点击“关闭”停止播放并释放资源。

支持 `[00:00:11-00:00:23] 文字`、`[00:11] 文字`。时间戳范围外不高亮。局部 ASR 估算误差需修正原稿时间戳。

## 手动安装

把发布附件中的 `main.js`、`manifest.json`、`styles.css` 放入库的 `.obsidian/plugins/shine-meeting-player/`，再启用插件。安装前建议保留旧版副本。

## 验证边界

已用模拟移动环境验证：Node/Electron 不可用时可加载、库内音频解析、音频选择、选词命令、时间戳与区间间隙。运行：`node test-mobile.cjs`。

仍需安卓实机验证媒体解码、长按选择和不同屏幕布局。锁屏/后台播放依赖系统行为，本测试版不作保证。播放前请确认音频已同步下载完成。插件不联网、不上传笔记或音频。
